# 名刺人脈検索システム 導入手順

スマホから「会社名・氏名・住所・業種・役職」で名刺を検索できる、非公開のWebアプリです。
**個人情報はGoogleの非公開スプレッドシートにのみ保存**し、公開領域（GitHub等）には一切置きません。
アクセスは**Googleログインの内側に限定**されます（自分のアカウントのみ）。

---

## 構成（$150のPlaces APIは不使用・実質無料）

```
[スマホ] ── Googleログイン ──> [GAS Web App(UI/検索API)] ──> [非公開スプレッドシート(名刺DB)]
```

- データ層：Google スプレッドシート「名刺DB」（限定共有・自分のみ）
- API/UI層：GAS HtmlService（このコード）。デプロイ設定で「自分のみ」アクセス
- 都道府県・業種・役職レベルは**住所と会社名から無料で自動付与**済み

---

## セットアップ（初回・約10分）

### 1. スプレッドシートを作る
1. Google ドライブで新規スプレッドシートを作成し、名前を「名刺DB」等にする
2. シート名（タブ）を **`名刺DB`** に変更する
3. メニュー **ファイル > インポート** から `名刺DB_初期データ.csv` を読み込む
   - インポート場所：**現在のシートを置き換える**
   - 区切り文字：**カンマ**　／　1行目が見出しになっていればOK
   - ※3,799件・先頭行が `id, 会社名, 部署名 …` の見出し

### 2. スクリプトを入れる
1. スプレッドシートのメニュー **拡張機能 > Apps Script** を開く
2. 既定の `コード.gs` の中身を、本フォルダの **`Code.gs`** で置き換える
3. 左の「＋」から **HTML** ファイルを追加し、名前を **`Index`** にして
   **`Index.html`** の中身を貼り付ける（ファイル名は拡張子なしで `Index`）
4. 保存

> clasp派の場合：`appsscript.json`＋`Code.gs`＋`Index.html` をそのまま `clasp push`。

### 3. Webアプリとして公開（自分だけがアクセス）
1. Apps Script 右上 **デプロイ > 新しいデプロイ**
2. 種類：**ウェブアプリ**
3. 次のユーザーとして実行：**自分**
4. アクセスできるユーザー：**自分のみ**　←ここがセキュリティの肝
5. デプロイ → 表示されたURLがアプリのURL

### 4. スマホで使う
1. スマホのブラウザで、上記URLを開く（**そのGoogleアカウントでログイン**しておく）
2. ブラウザの共有メニューから **ホーム画面に追加** → アプリのように起動できる

## 今後、残り約2,500件を追加する方法

毎回CSVを整形し直す必要はありません。**名寄せして自動追記**されます。

1. Eightから新しいCSVをダウンロード
2. そのCSVを Google ドライブにアップロードし、**ファイルID**を控える
   （ファイルを開いたURL `…/d/＜ここがファイルID＞/view` の部分）
3. スプレッドシートのメニュー **名刺DB > Eight CSVを取り込む（名寄せ追記）** を実行
4. ファイルIDを貼り付けてOK
   → 既存と重複する人（会社名＋姓＋名が同じ）は自動スキップ、新規だけ追加

※ Eightの元CSV（Shift_JIS）のまま取り込めます。都道府県・業種・役職レベルも取込時に自動付与されます。

---

## アクセス権を複数アカウントにしたい場合

`Code.gs` 冒頭の `ALLOWLIST` に許可メールを列挙し、デプロイの「アクセスできるユーザー」を
**全員（ただしGoogleアカウント必須）** にすると、リストのアカウントだけが使えます。
通常は「自分のみ」が最も安全です。

---

## よくある調整

- **検索の最大表示件数**：`Code.gs` の `RESULT_LIMIT`（既定200）
- **フリーワードの対象列**：`searchCards` 内の `fields` 配列
- **業種の精度を上げたい**：現在は会社名のキーワード判定（無料）。将来Claude Haikuで
  分類し直せば「その他」を大幅に減らせます（4,000件でも数百円規模）

---

## セキュリティ要点

- 公開リポジトリ等に**個人情報・APIキーを置かない**（このアプリはGoogle内部で完結）
- Webアプリは必ず「**自分のみ**」または許可リストでデプロイ
- 検索結果は条件に一致した分だけ返却（全件を一括公開しない）
